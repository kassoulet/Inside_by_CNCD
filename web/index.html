The original ran in VGA mode 13h (320×200, 256 colours, non-square pixels: shown on a 4:3 CRT). The canvas below is the real 320×200 index buffer, stretched to a 4:3 display box. The visuals are a pure function of the music position (the demo's own script table is keyed on AMF order/row), so you can seek anywhere. Music: EYE.AMF (what INSIDE.EXE loads via DSMI) rendered by libopenmpt.
